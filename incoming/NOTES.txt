Mise à jour 3.0.99 :

- Mise à jour GitHub : la détection ne dépend plus en priorité de l’API publique GitHub.
- L’application lit maintenant directement `releases/latest/download/update.json`, puis télécharge `WLM-Escargot-Android.apk` depuis la Latest Release.
- L’ancienne API `api.github.com/.../releases/latest` reste disponible en secours pour compatibilité.
- Les requêtes désactivent explicitement les caches HTTP afin d’éviter de conserver une ancienne Latest Release.
- Toutes les améliorations des clins d’œil de la 3.0.98 sont conservées.
- Package et signature de la branche 3.0 restent inchangés.
