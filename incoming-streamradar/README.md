# StreamRadar — dépôt des mises à jour

Déposer ici la nouvelle APK StreamRadar. Le workflow vérifie le package `ch.piiwii.streamradar`, choisit la versionCode la plus élevée, remplace automatiquement l’APK publique courante et met à jour `streamradar/latest.json`.

Optionnel : ajouter `NOTES.txt` pour les notes de version.
