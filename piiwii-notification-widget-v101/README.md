# PiiWii Notification Widget 1.0.1

Package: ch.piiwii.notificationwidget. versionCode: 2. Same package and update signature as 1.0.0.

## New features
- Absolute priority for physical charging, whether via cable or wireless charger. While plugged in, the selected “En charge” pictogram overrides notifications, calls and tests.
- As soon as the phone is unplugged, the original intelligent notification priority is restored automatically.
- Live charging status panel in the application with an explanation of the new behavior.
- All 27 categories, icon personalization, and the transparent resizable home-screen widget remain available.
- Charging category checkbox remains respected if it is manually disabled.
