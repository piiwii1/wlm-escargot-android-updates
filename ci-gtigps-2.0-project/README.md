# GTI GPS Widget 2.0.0 — Google Maps Window

Cette version abandonne MapLibre/OSRM. Elle ne remplace plus Google Maps : elle lance la vraie application Google Maps dans une fenêtre freeform positionnée sur la zone du widget.

- Package : ch.piiwii.gtigps
- versionName : 2.0.0
- versionCode : 5
- targetSdk : 28 (TS18 / Android 10)
- Google Maps requis : com.google.android.apps.maps
- Calibration visuelle X/Y/largeur/hauteur incluse
- Plein écran + retour fenêtre
- Fallback plein écran si le firmware bloque le mode freeform
